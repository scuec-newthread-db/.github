# 中南民族大学 DB 组 (SCUEC DB Lab)

中南民族大学计算机科学学院新思路实验室 DB 组官方代码空间。  
聚焦现代数据库内核研发、分布式系统、AI for DB 及学术前沿复现。

---

## 核心研究方向

- **数据库存储引擎与内核研发**：现代关系型与分析型数据库（RDBMS / OLAP）、LSM-Tree 存储引擎、向量化执行与并发控制；
- **AI for DB 与前沿机器学习**：学习型索引（Learned Index）、查询优化与软硬件协同；
- **智能体架构与前沿工程**：自主科研 Agent、上下文工程与多模型协同架构；
- **学术工具链与数据基础设施**：双语学术论文自动化交付管线、文献解析与大规模科研数据治理。

---

## 精选开源项目与工具

- **difflogic-reproduction**：NeurIPS 2022 顶会论文复现工程套件与交互式架构分析；
- **pdf2zh**：英文学术 PDF 至高保真双语 Markdown 的可验证交付管线（集成 MinerU OCR 与大模型翻译）；
- **caj2pdf**：中国知网（CNKI）CAJ 格式文献批量快速转标准 PDF 解码工具；
- **ai-paper-pipeline**：每日学术前沿追踪、自动化全文解析与期刊式早报分发流水线；
- **db-awesome-curated**：精选数据库内核、现代 C++ 与高性能系统开发全景导航地图。

---

## 组织协作与规范

- **工程脚手架**：组内工程开发统一基于 `db-template`（C++20 内核模板）与 `db-template-python`（Python 科研与算法模板）初始化；
- **代码规范**：共享代码库实行主干保护，改动须通过 Pull Request 提交并附带自动化单元测试；
- **管理准则**：遵循《实验室 DB 组 GitHub 组织管理与协作规范》，推行“自主建库、最低规范、分级协作、明确交接”。
